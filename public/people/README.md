# Speaker & organiser photos

Drop headshots here, then set the `image` path in the content files.

- Speakers → `src/content/speakers.ts` (add `image: "/people/<file>"`)
- Organisers / advisors → `src/content/people.ts`
- Panelists → `src/content/speakers.ts` (panel.panelists)

Recommended: square JP/PNG, ~400×400, named like `frank-noe.jpg`.
Example: `image: "/people/frank-noe.jpg"`.

If `image` is unset, an elegant initials avatar is shown automatically.
Use only photos you have the right to use (official profile / with permission).
